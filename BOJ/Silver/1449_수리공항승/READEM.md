# 백준 1449 - 수리공 항승

## 문제 핵심

물이 새는 위치가 여러 곳 주어지고, 길이가 `L`인 테이프로 모든 위치를 막아야 한다.

테이프를 붙일 때 물이 새는 위치의 좌우 `0.5`만큼을 추가로 막아야 하므로, 하나의 테이프로 덮을 수 있는 정수 위치의 범위는 다음과 같다.

```python
시작 위치 ~ 시작 위치 + L - 1
```

모든 물이 새는 위치를 막기 위해 필요한 테이프의 최소 개수를 구하면 된다.

---

## 풀이 방법

물이 새는 위치를 오름차순으로 정렬한 뒤, 가장 왼쪽에 있는 아직 막히지 않은 위치부터 테이프를 붙인다.

```python
lst.sort()
```

현재 붙어 있는 테이프가 덮는 마지막 위치를 `end`에 저장한다.

```python
end = 0
```

정렬된 물이 새는 위치를 왼쪽부터 확인하면서, 현재 위치 `x`가 기존 테이프의 범위를 벗어났다면 새로운 테이프를 사용한다.

```python
if x > end:
    cnt += 1
    end = x + l - 1
```

현재 위치가 `end` 이하라면 이미 붙인 테이프로 막을 수 있으므로 아무 작업도 하지 않는다.

---

## 예시

테이프 길이가 `2`이고 물이 새는 위치가 다음과 같다고 하자.

```python
1 2 100 101
```

위치 `1`부터 테이프를 붙이면 다음 범위를 막을 수 있다.

```python
1 ~ 2
```

따라서 위치 `2`는 이미 막혀 있다.

다음으로 위치 `100`은 기존 테이프의 범위를 벗어났으므로 새로운 테이프를 붙인다.

```python
100 ~ 101
```

총 필요한 테이프의 개수는 `2개`이다.

---

## 전체 코드

```python
import sys

input = sys.stdin.readline

n, l = map(int, input().split())
lst = list(map(int, input().split()))
lst.sort()

cnt = 0
end = 0

for x in lst:
    if x > end:
        cnt += 1
        end = x + l - 1

print(cnt)
```

---

## 시간 복잡도

물이 새는 위치를 정렬하는 데 다음 시간이 걸린다.

```python
O(N log N)
```

정렬된 위치를 한 번 순회하는 데 `O(N)`이 걸리므로 전체 시간 복잡도는 다음과 같다.

```python
O(N log N)
```
