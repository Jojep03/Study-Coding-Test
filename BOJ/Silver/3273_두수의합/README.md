# [Silver III] 두 수의 합 - 3273

[문제 링크](https://www.acmicpc.net/problem/3273)

## 문제 설명

서로 다른 양의 정수로 이루어진 수열이 주어졌을 때, 두 수의 합이 `x`가 되는 쌍의 개수를 구하는 문제이다.

수열의 크기 `N`과 수열의 원소들이 주어지고, 목표값 `x`가 주어진다.

이때

```text
ai + aj = x
```

를 만족하는 두 수의 쌍의 개수를 출력한다.

## 입력

첫째 줄에 수열의 크기 `N`이 주어진다.

둘째 줄에는 수열에 포함되는 `N`개의 서로 다른 양의 정수가 공백으로 구분되어 주어진다.

셋째 줄에는 목표값 `x`가 주어진다.

## 출력

두 수의 합이 `x`가 되는 쌍의 개수를 출력한다.

## 예제 입력

```text
9
5 12 7 10 9 1 2 3 11
13
```

## 예제 출력

```text
3
```

## 풀이 아이디어

두 수의 합이 `x`가 되는 경우를 찾아야 한다.

모든 두 수의 조합을 직접 확인하면 `O(N²)`의 시간이 걸릴 수 있다.

따라서 수열을 먼저 오름차순으로 정렬한 뒤 **투 포인터**를 사용한다.

정렬된 수열에서

* `left`는 가장 작은 값부터 시작
* `right`는 가장 큰 값부터 시작

두 값의 합을 확인하면서 포인터를 이동한다.

```text
lst[left] + lst[right]
```

현재 두 수의 합이 `x`보다 작다면 더 큰 값을 만들어야 한다.

따라서 작은 값을 가리키고 있는 `left`를 오른쪽으로 이동한다.

```text
합 < x
→ left += 1
```

반대로 현재 합이 `x`보다 크다면 더 작은 값을 만들어야 한다.

따라서 큰 값을 가리키고 있는 `right`를 왼쪽으로 이동한다.

```text
합 > x
→ right -= 1
```

두 수의 합이 정확히 `x`라면 조건을 만족하는 쌍을 찾은 것이므로 개수를 증가시킨다.

```text
합 = x
→ cnt += 1
```

이후 두 포인터를 모두 이동한다.

```text
left += 1
right -= 1
```

문제에서 수열의 원소는 서로 다른 값이기 때문에 이미 사용한 두 수를 다시 확인할 필요가 없다.

## 예시

예제 수열을 정렬하면

```text
1 2 3 5 7 9 10 11 12
```

이고 목표값은

```text
x = 13
```

이다.

처음에는

```text
left = 1
right = 12
```

이므로

```text
1 + 12 = 13
```

조건을 만족한다.

따라서 정답 개수를 증가시키고 두 포인터를 이동한다.

```text
left → 2
right → 11
```

다시 확인하면

```text
2 + 11 = 13
```

이므로 또 하나의 쌍을 찾을 수 있다.

이런 방식으로 배열을 한 번 탐색하면 된다.

## 코드

```python
import sys

input = sys.stdin.readline

n = int(input())
lst = list(map(int, input().split()))
x = int(input())

lst.sort()

left = 0
right = n - 1
cnt = 0

while left < right:
    temp = lst[left] + lst[right]

    if temp > x:
        right -= 1
    elif temp < x:
        left += 1
    else:
        cnt += 1
        left += 1
        right -= 1

print(cnt)
```



## 주의할 점

투 포인터를 사용하기 전에 반드시 수열을 정렬해야 한다.

```python
lst.sort()
```

정렬하지 않으면 합이 `x`보다 크거나 작을 때 어느 포인터를 이동해야 하는지 판단할 수 없다.

또한 반복문의 조건은

```python
while left < right:
```

로 작성해야 한다.

`left == right`가 되면 같은 원소 하나를 두 번 사용하는 것이므로 확인하면 안 된다.

## 시간 복잡도

수열을 정렬하는 데

```text
O(N log N)
```

이 걸린다.

정렬 이후 투 포인터로 수열을 한 번 탐색하므로

```text
O(N)
```

이 걸린다.

따라서 전체 시간 복잡도는

```text
O(N log N)
```

이다.
